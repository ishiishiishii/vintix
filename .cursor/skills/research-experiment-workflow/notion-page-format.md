# Notion 記録ページの書き方（研究の目的ごとのページ）

ユーザーの方針（原文）: もっとわかりやすくまとめられるように。結果はグラフや動画を用いて記録したり、大まかな内容と結果などをまとめた後に、トグルなどで詳細設定や詳細結果などを記載できると良い。つまり、もっとわかりやすくNotionに記録できるようにして。

読み手は「ページを開いて 1 分で、何が分かって・次に何をするか」を知りたい。
上から順に **結論 → 図 → 要点 → 次 → 詳細（トグル）→ 実行ログ（トグル）** の順に並べる。

## ページの構成（この順番・この見出し）

```markdown
<callout icon="📌">
	**いまの結論:** （1〜2 文。数値入り。暫定なら「暫定（シード 2/10）」のように根拠の量を書く）
	**状態:** 実行中（境界付近 71/520、PPO 未着手）／完了　｜　**最終更新:** 2026-11-04 19:30 — （前回からの変化を 1 文）
</callout>

## 目的
（2〜3 文。何を確かめたいか。専門用語は言い換える）

## 主な結果
![（図が示すことを 1 文で: 例「質量を変えたときの完走率と報酬。Vintix は軽い側で専門家より広く歩ける」）](https://raw.githubusercontent.com/ishiishiishii/vintix/<commit SHA>/vintix_go2/<実験>/figures/<図>.png)
（図の読み方を 1〜2 文: 横軸・縦軸・線の色・誤差棒の意味）

<table header-row="true">（要約表。5〜8 行まで。境界の前後など大事な行だけ）</table>

（動画があればここ。「歩ける例」と「崩れる例」を並べる）

## いま言えること
- （3〜5 個。数値付き。1 項目 1〜2 文）
- **まだ言えないこと:** （シード数・未切り分けの要因など）

## 次にやること・判断待ち
- （Issue 番号付き。判断待ちは何を決めてほしいかを書く）

## 実験設定（詳細） {toggle="true"}
	（全パラメータの表、設計の理由、使ったモデル・データ）

## 詳細結果 {toggle="true"}
	（全点の表、補足の図、シードごとの値、生データの場所）

## 実装・再現方法 {toggle="true"}
	（実験ディレクトリ、主要ファイル、実行コマンド、ブランチ、Issue）

## うまくいかなかったこと → 修正 {toggle="true"}
	（時系列で短く）

## 実行ログ
（ここだけ見出しはトグルにしない。各エントリをトグル見出しにして末尾に追記する）

### 2026-11-04 19:30 （何が分かったかを見出しにする。例「質量 1.15〜1.25 倍の Vintix はシードで大きくぶれる」） {toggle="true"}
	- **実行内容:** …
	- **結果:** …（図があれば埋め込む。表は 10 行程度まで）
	- **考察:** 言えること／まだ言えないこと
	- **次:** …（Issue 番号）
```

## 書き方のルール

- **先頭のコールアウトと「主な結果」「いま言えること」は毎回最新に書き換える**。古い結果を上に残さない
  （古い数値は「詳細結果」か実行ログへ移す）。実行ログは追記のみ。
- 実行ログの見出しは「やったこと」ではなく「分かったこと」にする。新しい結果が無い監視だけの回はエントリを作らない
  （コールアウトの「状態」「最終更新」だけ更新する）。
- 数値には単位と根拠の量（シード数、エピソード数）を付ける。暫定値は「暫定」と書く。
- 1 段落 3 文まで。表は要約 5〜8 行・詳細でも 15 行程度まで（それ以上は CSV のパスを書く）。
- 専門用語は初出で言い換える（例: 完走率 = 1000 step 転倒せずに終わったエピソードの割合）。
- トグルの中身はすべてタブ 1 段でインデントする（インデントしないとトグルの外に出る）。`<` `>` はエスケープしない。

## 図・動画の載せ方（Notion API に画像アップロードが無いため GitHub 経由）

1. 図は実験ディレクトリの `figures/` に、内容と日付が分かる名前で保存する（例: `mass_completion_return_20261104.png`）。
   PNG・dpi 110 前後・1 MB 以下。図中の文字は英語でよい（コンテナに日本語フォントが無い）。軸ラベルに単位を書く。
   密集した横軸は等間隔に並べる、凡例は線と重ねない、など一目で読めるように作る。
2. `*.png` は `.gitignore` 対象なので `git add -f vintix_go2/<実験>/figures/<図>` で明示的に追加してコミット・push する
   （リポジトリは公開。載せてよい図だけを置く。`graphs/` などの自動生成物は追加しない）。
3. Notion には **コミット SHA 固定の URL** で埋め込む:
   `https://raw.githubusercontent.com/ishiishiishii/vintix/<SHA>/vintix_go2/<実験>/figures/<図>.png`
   （ブランチ名の URL だと後で図が差し替わり、過去の実行ログの図まで変わってしまうため）。
   埋め込み前に `curl -sI <URL>` で 200 と `content-type: image/png` を確認する。
4. 動画は 5〜10 秒の GIF（5 MB 以下）にして同じ方法で画像として埋め込む。MP4 は `<video src="<raw URL>"></video>`
   を試し、再生できない場合はリンクにする。代表は「歩ける例」「崩れる例」の 2 本。
5. 図は対応する表・文章の直後に置く（ページ末尾にまとめて貼らない）。キャプションに「何が分かる図か」を書く。

## README との対応

実験ディレクトリの `README.md` 末尾「実行ログ」には同じエントリを Markdown で書く（トグルは見出しと箇条書きにし、
図は `figures/<図>.png` の相対パスで `![](figures/...)` と埋め込む）。
