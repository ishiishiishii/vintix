# Issue 本文テンプレート

`gh issue create -R ishiishiishii/vintix -t "<題名>" -l <ラベル> -F body.md` で使う。題名は短い日本語。

## task（ユーザーからの課題）

```markdown
## 依頼内容
（ユーザーの依頼をそのまま、または要約）

## やること
- [ ] …

## 完了条件
…

## 関連
- 実験ディレクトリ: `vintix_go2/<name>/`
- ブランチ: `exp/<name>`
- Notion: <URL>
```

## discussion（壁打ちの記録）

```markdown
## 論点
…

## 議論の要点
- …

## 決定事項
- …

## 未解決・次に確かめること
- [ ] …
```

## experiment（やるべき実験）

```markdown
## 目的・問い
…

## 仮説
…

## 方法・設定
| 項目 | 値 |
|------|-----|

## 見積もり
GPU 時間: 約 ◯ 時間（評価 ◯ 本 × ◯ 分 など）

## 完了条件
…

## 関連
- 元になった結果・Issue: #…
```

## 進捗コメント

```markdown
**進捗（YYYY-MM-DD）**
- やったこと: …
- 結果: …（数値、`<図のパス>`）
- 考察: …
- 次: …
```
