# 比較実験の進め方（Issue #22）

論文やレポートでは、略語やこのリポだけの言い方をそのまま置かない。
必要なときは括弧で一度だけ言い換える。

| わかりやすい呼び方 | 意味 |
|------|------|
| Go1 のデータだけで学習した Vintix | Issue #18。Go1 の学習履歴だけで学習したモデル |
| 多様な体のデータで学習した Vintix | Issue #21。重さ・大きさを変えた成功履歴で学習したモデル |
| 汎用歩行の比較手法 | GenLoco / URMA / MorFiC など、このディレクトリで扱う他手法 |

## 指標（本リポと揃える）

- 完走率: 1000 ステップ転倒なしで終わったエピソードの割合
- 前進速度・指令への追従（取れる場合）
- **公式シミュレータでの数値**と **Genesis に近似して配線した数値**は別の列にする（差分を書く）

## 方針（移植が重い場合）

1. まず公式シミュレータで、公式の学習済み重みを再生して数値を取る
2. Genesis への配線は任意・参考値（観測の近似が残ることを明記）
3. タスク定義が違う手法（例: GenLoco は動きの模倣、本線は速度追従）は「タスクの違い」列を残す
