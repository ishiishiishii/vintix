## いま言えること

- **倒れにくさ（完走）:** 両機体とも短評価では完走率 100%。「立って歩き切る」だけなら第1波の最低ラインは満たしている
- **速度の追従（報酬）:** Aliengo ≈22 に対し B1 ≈2–6。同じ報酬スケールでも **約 4〜10 倍の差**。B1 の履歴は「長く生き残るが、指令速度への追従は弱い」可能性が高い
- **学習の型:** B1 は中盤で一度歩けてから崩れる型。密な保存＋短評価で歩行重みを拾えた。最終の学習ログ長だけでは不合格に見えてしまう
- **収集中の様子（B1・model_40）:** 探索ノイズ ε≈0.02、直近エピソード長 ≈**810–920**、直近報酬 ≈**+3.2**。長さは少し下がったが 800 超を維持 → 収集自体は健全

## まだ言えないこと

- B1 履歴を Vintix の学習データに入れたとき、Aliengo 並みに効くか（未学習）
- return ≈2 が「追従不足」なのか「報酬スケール／指令の差」なのかの切り分け（追加の速度誤差ログが必要）
- ANYmal-B / Spot が同じ「完走は高いが return は低い」型になるか

## 運用上の含意

1. B1 第1波は **完了扱いにしてよい候補**（完走 100%＋履歴 ≈200万）。ただし論文で「専門家の強さ」を主張するなら Aliengo と並べて return 差を明記する
2. 追従を上げたい場合の次手（任意・本線の後）: 目標速度誤差の診断 → 追加学習／指令レンジ調整。いまの優先は ANYmal-B へ進むこと
3. 次機体でも「完走率」と「平均報酬」を必ずペアで記録する（どちらか一方だけだと誤解する）
